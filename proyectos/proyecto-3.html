Pipeline de Datos Medallion: de MongoDB a Analítica OLAP

Una solución integral que transforma datos semiestructurados en indicadores listos para explorar mediante dashboards interactivos.

Ingeniería de datos
Arquitectura Medallion
Analítica OLAP

Resumen Ejecutivo

Pipeline automatizado, desarrollado en Python, que extrae documentos semiestructurados desde MongoDB y los transforma siguiendo la Arquitectura Medallion. Los datos refinados se almacenan en DuckDB para su consulta analítica y se exponen mediante una API con FastAPI para alimentar dashboards interactivos creados con Chart.js.

El Problema

MongoDB ofrece flexibilidad para las aplicaciones operativas, pero sus documentos anidados y esquemas variables dificultan el análisis complejo y pueden hacer costosos los reportes ejecutados directamente sobre la base transaccional.

  • Las estructuras anidadas complican las consultas y agregaciones analíticas.
  • Los reportes sobre el origen pueden competir por recursos con las operaciones de la aplicación.
  • Los dashboards necesitan datos limpios, tipados y preparados para consultarse con rapidez.

Capacidades Principales

Transformación de datos

Aplana documentos JSON anidados, normaliza tipos y aplica reglas de limpieza y calidad.

Capas Bronze, Silver y Gold

Conserva el dato original, prepara una versión depurada y genera modelos y agregados analíticos.

Consultas OLAP con DuckDB

Traslada las consultas analíticas a un motor columnar separado de la carga transaccional.

Indicadores interactivos

Entrega datos procesados a una API para visualizarlos en gráficos dinámicos con Chart.js.

Arquitectura de la Solución

El flujo separa la ingesta, el procesamiento, el almacenamiento analítico y la visualización. Así, cada etapa puede evolucionar y escalar sin acoplar los dashboards directamente a las colecciones operativas de MongoDB.

  1. Origen: Python se conecta a MongoDB e ingesta documentos JSON/BSON de las colecciones seleccionadas.
  2. Bronze: Guarda una copia de los datos crudos para conservar su trazabilidad y respaldo histórico.
  3. Silver: Trata valores nulos, aplana estructuras anidadas, normaliza tipos y valida reglas de calidad.
  4. Gold: Modela y agrega los datos para preparar tablas de análisis y el cálculo de indicadores.
  5. Exposición: DuckDB almacena las tablas analíticas y FastAPI ofrece endpoints que las sirven como JSON.
  6. Visualización: Chart.js consume la API y presenta métricas y tendencias en gráficos interactivos.

Impacto y Beneficios

  • Datos trazables: La separación en capas permite seguir el recorrido desde el dato crudo hasta el indicador.
  • Menor carga analítica en el origen: Los reportes consultan DuckDB en lugar de competir directamente por recursos con las operaciones de MongoDB.
  • Análisis ágil: El almacenamiento columnar y una API dedicada están orientados a servir resultados analíticos con baja latencia.
  • Diseño modular: Se pueden incorporar nuevas colecciones o fuentes sin rehacer la capa de visualización.
